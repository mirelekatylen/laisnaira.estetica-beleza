# Laisnaira Estética e Beleza

## Sobre o projeto

Este projeto consiste no desenvolvimento de um site institucional para a marca Laisnaira Estética e Beleza, com o objetivo de apresentar a profissional, divulgar seus serviços e facilitar o contato com as clientes.

O site foi desenvolvido manualmente com HTML, CSS e JavaScript, buscando uma identidade visual elegante, acolhedora e responsiva.

## Páginas do site

- **Início:** apresentação da marca e destaques dos serviços.
- **Sobre:** apresentação da profissional e de suas especializações.
- **Serviços:** informações sobre os procedimentos oferecidos.
- **Avaliações:** exibição de avaliações de clientes e perguntas frequentes.
- **Contato:** informações e opções de contato.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Google Fonts

## Recursos

- Layout responsivo para computadores e dispositivos móveis.
- Menu de navegação adaptado para dispositivos móveis.
- Carrossel de avaliações.
- Perguntas frequentes interativas.
- Identidade visual personalizada.

## Publicação

O site está hospedado na Netlify e conectado ao GitHub para atualização automática após o envio das alterações ao repositório.
